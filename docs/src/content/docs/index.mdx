## Two panes, one session

<CardGrid>
  <Card title="Chat" icon="comment">

[Two panes, one extension](/cv4vs-agents/two-panes/).

## What sets it apart

<CardGrid>
  <Card title="The IDE as tools" icon="puzzle">
    79 MCP tools hand the agent Visual Studio's own navigation, references, rename, diagnostics,
    build and Test Explorer. Not text search over source: the IDE's semantic view of your program.

    [MCP tools](/cv4vs-agents/mcp-tools/)
  </Card>
  <IconCard title="The live debugger" icon="bug">
    Stop on an exception and one press asks about the break: the agent reads the live stack and
    locals rather than guessing from the source.

    [Debug with the agent](/cv4vs-agents/guides/debug-with-the-agent/)
  </IconCard>
  <Card title="Changes in Visual Studio's own diff" icon="approve-check-circle">
    Every Edit shows as an inline diff, and opens in Visual Studio's native side-by-side one, with
    the editor's own colouring and navigation.

    [Reviewing changes](/cv4vs-agents/chat/diff/)
  </Card>
  <Card title="The same CLI as VS Code" icon="vscode">
    It drives the real `claude.exe`, so sessions, commands, plugins and settings are the ones the VS
    Code extension and the terminal see.

    [Compared with the VS Code extension](/cv4vs-agents/claude/vs-code-differences/)
  </Card>
</CardGrid>

## Start in three steps

<Steps>

1. **Install the Claude Code CLI.** The extension drives it and never bundles it.

   ```powershell
   winget install Anthropic.ClaudeCode
   ```

2. **Install the extension** from the
   [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=Corsinvest.cv4vs-agents),
   or search *cv4vs Agents* in **Extensions → Manage Extensions**.

3. **Open a pane**: **View → cv4vs Agents → Claude**.

</Steps>

The whole walkthrough is in [Getting started](/cv4vs-agents/getting-started/).

## Who makes it

cv4vs Agents is an independent, open source extension (GPL-3.0) by
[Corsinvest Srl](https://www.corsinvest.it), made in Italy. It drives the real `claude.exe`, which
